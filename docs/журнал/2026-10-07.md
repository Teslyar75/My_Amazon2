## 3. Mobile / Expo Go

### Проблема
На телефоне красная плашка «Product unreachable»:  
`EXPO_PUBLIC_PRODUCT_URL=http://localhost:5272` указывает на **сам телефон**, а API слушал только `127.0.0.1`.

### Исправление
| Слой | Что |
|------|-----|
| API | `ASPNETCORE_URLS=http://0.0.0.0:5272` — доступ с LAN (`192.168.x.x`) |
| Mobile | `src/api/productOrigin.ts` — native подставляет IP хоста Metro из Expo |
| Media | `resolveMediaUrl` использует тот же origin |
| EAS prep | `eas.json` (preview APK), splash, `perry://product/{id}`, `expo-constants` |

### Проверено
- Expo Web `:8081` + API health.  
- Wishlist: сердце на PDP после логина → `Added to wishlist`, `POST /api/wishlist` 200 (подтверждено на устройстве).  
- Локальный Gradle APK — JVM crash на машине (мало RAM/диска); cloud EAS — нужен `eas login` (Teslyar75 / Access Token).
