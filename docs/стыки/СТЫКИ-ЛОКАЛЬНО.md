## Что взять у Влада (#97) — лично, не в чат команды

1. **`serviceName`** (ожидаем `local-service`, уточнить если другой)  
2. **`ServiceCredential` plaintext** (тот же, от которого у него `CredentialHash`)  
3. Подтверждение endpoint: `POST /internal/auth/token` → `{ accessToken, expiresIn }`  
4. (опционально) живой пример JWT payload: только имена claims + `iss`/`aud` — **без** полного token

Вписать в локальный `.env` (из `My_Amazon2/.env.example`):

```env
AuthService__ServiceName=local-service
AuthService__ServiceCredential=<plaintext от Влада>
```

Проверка (API в Development):

```text
GET http://localhost:5272/api/dev/auth-internal-status
→ credentialConfigured: true, tokenOk: true
```
